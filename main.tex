\section*{Data Availability}

The four source phenotype--genotype datasets analysed in this study are available from their original publications or compiled phenotype-matrix sources: ATLeaf~\cite{Schafer2023-nk}, Biolog phenotype data~\cite{BiologDatasetCitation}, Marine~\cite{Gralka2023-ft}, and Populus (this study).
The Populus Biolog carbon-source phenotype matrix analysed here is provided in the Zenodo deposit, and the corresponding genome accessions are listed in the deposited accession table.
% TODO(CITATION): Biolog dataset now cites the reserved KBase/OSTI DOI 10.25982/149351.18/3374972; need to verify the dataset metadata (author, title, year) once the DOI is released. The Populus Biolog Excel file is bundled in the Zenodo deposit.
Processed feature matrices (KOFAM, RAST, and GapMind), phenotype labels, GapMind concordance labels and pathway calls, predicted proteomes for all analysed genomes, trained CatBoost model checkpoints, a genome accession table, and figure source data generated during this study are deposited at Zenodo under DOI~\url{https://doi.org/10.5281/zenodo.21223429}. % TODO(DEPOSIT): publish the draft Zenodo record before submission; confirm whether this is the concept (all-versions) or version-specific DOI; export the final Zenodo citation, add it to references.bib, and cite it here.
Computational genome annotations (RAST, KofamScan, GapMind) were produced using the cited tools on the assemblies described in Supplementary Text~S1--S2.
Genome assemblies are available from public repositories (NCBI and JGI IMG) via the accessions listed in the deposited accession table; the Biolog genome set is distributed through its KBase deposit~\cite{BiologDatasetCitation}.

\section*{Code Availability}

The machine learning pipeline and Python library are available at \url{https://github.com/kbasecollaborations/trait-prediction}.
The manuscript source, analysis scripts, and figure generation code are available at \url{https://github.com/kbasecollaborations/trait-prediction-manuscript}.
