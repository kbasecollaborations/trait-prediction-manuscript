\begin{abstract}
{
\noindent
Predicting microbial carbon utilization from genomic data remains challenging despite well-characterized metabolic pathways.
We compiled growth phenotypes for 819 microbial genomes across 242 carbon sources from four independent datasets and developed phenotype-specific classifiers to investigate whether machine learning can learn mechanistic features, why generalization fails, and how to improve performance.

Baseline mechanistic predictions (GapMind) achieved only modest accuracy ($\sim$0.65--0.70 balanced accuracy), while phylogeny-based methods failed to generalize beyond training distributions.
Machine learning models achieved strong within-dataset accuracy (0.75--0.90) but exhibited substantially reduced cross-dataset and out-of-clade performance (0.50--0.75).
Diagnosis revealed distinct failure modes: GapMind misclassifications showed no systematic directional bias, indicating multiple underlying causes (annotation gaps, regulatory complexity, measurement issues); ML generalization failures stemmed from learning dataset-specific rather than mechanistically relevant features.

Critically, ML can learn actual mechanisms when trained appropriately.
Models trained on samples where GapMind predictions matched experimental outcomes (concordant data) achieved near-perfect accuracy ($>$0.95) that generalized robustly and consistently identified established pathway genes as top features.
Moreover, these concordant-trained models predicted a subset of GapMind-discordant samples accurately (balanced accuracy 0.18--0.60), demonstrating that ML captures features beyond GapMind's curated gene sets.

We evaluated multiple improvement strategies: removing problematic genomes and confidence-based filtering of measurements improved cross-dataset performance modestly, while combined feature representations improved within-dataset but not cross-dataset accuracy.
Learning curves established that 50--100 high-quality samples per phenotype achieve robust generalization.

Our findings demonstrate that data quality, not algorithmic complexity, fundamentally constrains genotype-phenotype prediction.
Strategic data curation may be more valuable than brute-force data aggregation for building generalizable models.
}
\end{abstract}

\keywords{Machine learning, Microbial phenotypes, Genotype-phenotype mapping, Carbon utilization}
