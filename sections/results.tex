\section*{Results}

\subsection*{Core Story Arc}

\textbf{Goal:} Build carbon utilization prediction models to learn novel mechanistic features. When generalization issues arise or models don't use mechanistic features, diagnose why and develop improvement strategies.

\textbf{Narrative flow:}
\begin{enumerate}
\item Baseline approaches (GapMind, phylogeny) show limited accuracy, motivating ML approaches (Figure~\ref{fig:baseline_predictions})
\item ML models perform well on intra-dataset/random splits but fail to generalize across datasets and phylogenetic contexts (Figure~\ref{fig:ml_performance})
\item Why are predictions failing? GapMind misclassifications reveal annotation gaps and regulatory issues; ML generalization failures stem from learning non-mechanistic features (Figure~\ref{fig:misclassification_diagnosis})
\item Can ML learn actual mechanisms? Yes—when trained on GapMind-concordant data where mechanisms are clear, ML achieves high accuracy and learns mechanistic features. ML also predicts some discordant samples better than GapMind (Figure~\ref{fig:concordant_analysis})
\item Strategies to improve models: removing bad data, adjusting probability thresholds for precision, using confidence estimates, curriculum learning (Figure~\ref{fig:improvement_strategies})
\item Additional improvements: learning curves show sample requirements, feature representation combinations provide modest gains, dataset aggregation helps (Figure~\ref{fig:model_optimization})
\end{enumerate}

\subsection{Machine Learning Performance: Strong Intra-Dataset Results but Generalization Issues}

\textbf{Key finding:} ML models achieve high accuracy on intra-dataset and random splits but show substantial performance degradation across datasets and phylogenetic contexts.

\begin{figure}[h]
\centering
\includegraphics[width=0.95\textwidth]{figure3.pdf}
\caption{\textbf{Machine learning models excel within datasets but struggle to generalize.} (A) Intra-dataset random cross-validation achieves high balanced accuracy (0.80--0.90) across phenotypes, substantially better than GapMind baselines. (B) Cross-dataset evaluation using all pairwise dataset combinations reveals systematic generalization failures: performance drops of 0.15--0.25, with cross-dataset accuracy (0.60--0.70) approaching or falling below GapMind permissive baseline. (C) Phylogeny-independent (in-clade) splits show reduced performance compared to random splits, with out-of-clade splits showing further degradation, quantifying independent contributions of dataset bias and phylogenetic distance. (D) Direct comparison to GapMind performance: ML advantage diminishes or reverses under cross-dataset and out-of-clade evaluation, suggesting models learn dataset-specific rather than universal patterns.}
\label{fig:ml_performance}
\end{figure}

\caption{\textbf{What strategies improve model performance?} (A) \textit{Removing bad data:} Using insights from Figures 4 and 5, we identify problematic samples. Per-genome analysis reveals errors concentrated in top 10--20\% of genomes showing systematic issues (zero growth on all substrates, growth on $>$90\% of substrates, or poor annotation). Removing these genomes improves cross-dataset balanced accuracy by 0.03--0.08. Dataset-level filtering (removing high-discordance datasets) shows similar gains. (B) \textit{Improving precision:} For applications requiring high confidence predictions, tuning probability thresholds from default 0.5 to 0.7--0.8 dramatically improves precision (0.85 $\rightarrow$ 0.95) with acceptable recall reduction, enabling deployment for experimental follow-up. (C) \textit{Measurement confidence filtering:} Filtering training samples by experimental measurement confidence (using replicates, OD thresholds, growth curve quality) improves cross-dataset generalization by 0.05--0.10 balanced accuracy. (D) \textit{Feature confidence filtering:} Filtering by annotation quality scores (e.g., KOFAM/RAST confidence, alignment scores) shows modest improvements of 0.02--0.05 balanced accuracy. (E) \textit{Curriculum learning:} Training first on high-confidence concordant samples, then progressively adding lower-confidence and discordant samples, shows marginal performance gains (0.02--0.04) compared to direct concordant training, suggesting diminishing returns for added complexity.}
\label{fig:improvement_strategies}
\end{figure}

(B) \textit{Sample requirements depend on evaluation rigor:} Random within-dataset splits achieve balanced accuracy $>$0.85 with $\sim$30 samples; cross-dataset evaluation requires $\sim$50 samples; out-of-clade phylogenetic splits require $\sim$60--80 samples. (C) \textit{Do feature combinations help?} Combining KOFAM and RAST annotations provides marginal improvement (0.02--0.05 balanced accuracy) over KOFAM alone. Additional annotation sources show diminishing returns. \textit{Is it worth the computational cost?} For most applications, KOFAM alone is sufficient; feature combinations may help when sample sizes are very limited ($<$40). However, aggregation may be valuable when individual datasets have limited coverage of specific phenotypes or phylogenetic groups.}

\subsection{Summary and Practical Recommendations}

\textbf{Key insights from this work:}

\begin{enumerate}
\item \textbf{ML can learn mechanistic features}, but only when trained on samples with clear genotype-phenotype mappings (GapMind-concordant data). Full datasets contain noise that leads to spurious correlation learning.

\item \textbf{ML outperforms GapMind} by correctly predicting a subset of discordant samples, capturing features beyond GapMind's curated gene sets.

\item \textbf{Multiple improvement strategies exist:}
\begin{itemize}
\item Most impactful: Training on concordant data (primary strategy from Figure 5)
\item Modest gains: Removing systematically bad genomes/datasets, confidence-based filtering, curriculum learning (Figure 6)
\item Secondary optimizations: Feature combinations, dataset aggregation (Figure 7)
\end{itemize}

\item \textbf{Sample size requirements are manageable:} 40--60 concordant samples per phenotype achieve high performance, though out-of-clade generalization requires 60--80 samples.

\item \textbf{Rigorous evaluation is critical:} Cross-dataset and out-of-clade splits provide realistic performance estimates; random within-dataset CV overestimates generalization by 0.15--0.25.

\item \textbf{Deployment considerations:} Probability threshold tuning enables precision-focused predictions for experimental follow-up, while default thresholds balance precision and recall for screening applications.
\end{enumerate}

\textbf{Practical workflow for building generalizable models:}
\begin{enumerate}
\item Evaluate using cross-dataset/out-of-clade splits to avoid overly optimistic estimates
\item When mechanistic predictions (e.g., GapMind) are available, train on concordant samples
\item Without mechanistic knowledge, use feature stability diagnostics (high cross-dataset Jaccard $>$ 0.5 indicates mechanistic learning) and per-genome quality assessments
\item Collect 40--80 high-quality samples per phenotype; prioritize quality over quantity
\item Apply improvement strategies (Figures 6--7) for incremental gains
\item Tune deployment thresholds based on application requirements
\end{enumerate}
