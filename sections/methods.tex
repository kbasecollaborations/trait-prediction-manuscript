\section*{Materials and Methods}

\subsection*{Carbon Source Utilization Datasets}

We compiled four binary growth datasets capturing growth outcomes of phylogenetically and ecologically diverse bacterial strains across various carbon sources.
ATLeaf \cite{Schafer2023-nk} comprised 224 strains tested on 45 carbon substrates using minimal media on agar plates.
Biolog encompassed 362 strains across 64 substrates, compiled from published studies using Biolog Phenotype MicroArray technology \cite{Bochner2001PM,Bochner2009PM}.
% CITATION ADDED: Biolog PM technology references (resolved empty cite)
Marine \cite{Gralka2023-ft} contained 175 marine heterotrophic bacteria assessed across 100 carbon substrates.
Populus~\cite{Timm2015Populus} included 58 bacterial isolates tested on 191 carbon sources.

Due to annotation pipeline limitations and incomplete phenotypic data, the final datasets used for analysis contained fewer genomes and phenotypes than the original datasets (Supplementary Table~\ref{tab:dataset_overview}).
All analyses focused on the 15 shared phenotypes across all datasets.
We used ATLeaf, Biolog, and Marine datasets for model training and testing, reserving Populus for independent validation.
We standardized carbon source nomenclature across datasets using a phenotype name normalization protocol.

\subsection*{Genome Annotation}

We processed all bacterial genomes through a standardized annotation pipeline using three complementary tools.
Rapid Annotation using Subsystem Technology (RAST) \cite{Aziz2008RAST} provided functional predictions, with results parsed to extract subsystem ontology terms.
KEGG Orthology-based annotation used KofamScan \cite{Aramaki2020KofamKOALA}, which assigns KEGG Orthologs (KOs) via profile HMMs from the KEGG database \cite{Kanehisa2000KEGG}, annotating each genome individually in parallel.
GapMind (Price et al., 2020) predicted metabolic pathway completeness for carbon utilization, with pathway scores ranging from 0 (incomplete) to 2 (high confidence).

\subsection*{Phylogenetic Tree Construction}

We constructed a comprehensive phylogenetic tree incorporating microorganisms from all phenotype datasets using the Genome Taxonomy Database (GTDB) \cite{Parks2018GTDB} as a reference.
Phylogenetic distances were calculated using the ETE 3 toolkit \cite{HuertaCepas2016ETE3}.

\subsection*{Baseline Predictors}

\subsubsection*{GapMind Mechanistic Predictions}

We evaluated GapMind as a mechanistic baseline predictor by applying two thresholds to pathway completeness scores: strict (requiring complete pathways) and permissive (allowing likely complete pathways).

\subsubsection*{Phylogeny-Based Nearest Neighbor}

We implemented a phylogenetic nearest-neighbor classifier that predicts phenotypes based on the $k=3$ closest relatives in the training data, assigning the phenotype by majority vote.

\subsubsection*{Null Models}

We implemented two additional null models: an identity model (assigns the most common training class) and a Bernoulli model (assigns phenotypes according to observed training class probabilities).

\subsection*{Data Pre-processing and Feature Selection}

Feature representations from KOFAM and GapMind annotations were converted to binary presence/absence matrices (except GapMind pathway scores, which retained numeric values).
We implemented two-stage filtering on the combined dataset across all training data:
\begin{itemize}
    \item Variance filtering: Removed features with variance below 0.01 using scikit-learn's \cite{Pedregosa2011Sklearn} VarianceThreshold
    \item Correlation filtering: Removed highly correlated features (Spearman $\rho > 0.95$) using a graph-based approach that retains features with highest connectivity
\end{itemize}
KOFAM annotations yielded approximately 4000--5000 features per dataset after filtering; GapMind features yielded approximately 1000 features.
All filtering was performed on training data to prevent data leakage.

\subsection*{Machine Learning Classifiers}

We trained gradient-boosted tree classifiers using CatBoost \cite{Prokhorenkova2018CatBoost}, which showed slightly better performance than random forests in preliminary comparisons.
CatBoost was configured with the following parameters: 1000 iterations, learning rate 0.03, tree depth 4, L2 regularization 15, random subspace method (10\% features per split), Bayesian bootstrap, and early stopping with patience of 50 iterations.
% REVISION: corrected split ratio to match code (70:15:15)
For random splits, training used a 70:15:15 train:validation:test split; for cross-dataset and phylogenetic splits, the non-test data were split 85:15 for train:validation.
Early stopping was based on validation set Logloss, with balanced accuracy used as the primary reporting metric to account for class imbalance in phenotype data.
All experiments used random seed 42 for reproducibility.

\subsection*{Evaluation Strategies}

\subsubsection*{Cross-Validation and Cross-Dataset Testing}

We evaluated model performance using four scenarios: (i) random cross-validation within the aggregated dataset, (ii) cross-dataset evaluation (training on three datasets, testing on the held-out fourth), (iii) in-clade cross-dataset evaluation restricted to phylogenetically similar samples, and (iv) out-of-clade evaluation on phylogenetically distant samples.
Phenotype--dataset combinations with fewer than 10 test samples or 10 minority-class samples were excluded.
For cross-dataset testing, we mapped features from training data to test data, imputing missing features as zero values.

\subsubsection*{Phylogenetic Partitioning}

We implemented the out-of-clade partitioning algorithm described by \cite{Li2023-up}, which systematically separates training and test data based on phylogenetic relationships.
% REVISION: corrected test set range to match code (12--18%)
The algorithm selects test clades based on a target test set size range (12--18\% of samples) while ensuring phylogenetic separation from training data.
We supplemented this with manual class-level partitioning using Gammaproteobacteria and Alphaproteobacteria as out-of-clade test cases.

\subsection*{Concordant and Discordant Sample Analysis}

To assess whether ML models learn mechanistic features, we stratified samples based on agreement between GapMind predictions and experimental outcomes.
Concordant samples are those where GapMind predictions match experimental results (correct predictions by the mechanistic model).
Discordant samples are those where GapMind predictions contradict experimental results (false positives or false negatives).
We trained models on concordant samples only and evaluated performance on both concordant and discordant test sets to assess whether learned features generalize beyond the mechanistic predictor's coverage.

This approach is not circular: GapMind provides a single aggregate pathway-completeness prediction, whereas ML models must learn which specific genes among approximately 1,000 features are predictive for each phenotype.
However, concordance filtering may preferentially select samples where the canonical pathway is the actual mechanism, potentially excluding organisms using alternative metabolic routes (see Discussion).

\subsection*{Feature Importance Analysis}

We identified stable predictive features using SHAP (SHapley Additive exPlanations) analysis \cite{Lundberg2017SHAP}.
For SHAP analyses, we used a fixed 500-iteration CatBoost variant without early stopping (to avoid validation-set dependence).
For each phenotype and dataset configuration, we trained models across 20 random seeds, extracting the top 10 features by mean absolute SHAP value from each run.
Features appearing in at least 70\% of runs were designated as ``stable features.''
We compared stable features across datasets to assess whether models learn consistent mechanistic signatures or dataset-specific patterns.

\subsection*{Data Quality Filtering Strategies}

We explored alternative approaches to improve model generalization beyond concordant sample filtering.

\subsubsection*{Problematic Sample Identification}

We identified systematically problematic samples: microbes showing zero growth on all substrates, microbes showing universal growth despite incomplete GapMind pathways, and the 20 genomes with the highest total GapMind misclassification count across all 15 phenotypes.

\subsubsection*{Confidence-Based Filtering}

We developed a composite confidence score combining three information sources:
\begin{itemize}
    \item Phylogenetic confidence ($w=0.2$): Agreement among $k=3$ nearest phylogenetic neighbors
    \item GapMind confidence ($w=0.3$): Pathway completeness score from GapMind
    \item Experimental data ($w=0.5$): Binary experimental outcome
\end{itemize}
Weights were assigned to reflect the relative reliability of each information source: experimental measurements received the highest weight (0.5) as direct observations, GapMind pathway completeness received intermediate weight (0.3) as a mechanistic predictor, and phylogenetic neighbor agreement received the lowest weight (0.2), consistent with our finding that phylogenetic similarity is a relatively weak predictor of metabolic phenotypes (Figure~\ref{fig:baseline_predictions}).
The specific values were selected empirically.
GapMind confidence was mapped to a graded six-level scale (0.0--1.0) based on pathway completeness categories.
Samples with composite confidence scores between 0.4 and 0.6 were considered ambiguous and excluded from filtered training sets.

\subsection*{Sample Size Requirements}

We assessed minimum training data requirements using learning curves.
For selected phenotypes, we trained models on subsets of training data (50, 100, 200, 500, and full samples) using stratified subsampling with 3 repeats per configuration.
Performance was evaluated across random, cross-dataset, and out-of-clade splits, and on full, concordant, and discordant test subsets.
