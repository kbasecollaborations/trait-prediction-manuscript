\begin{figure}[h]

\caption{
\textbf{Diagnosing GapMind misclassifications and ML generalisation failures.}
(A) Conceptual framework outlining causes of concordant samples (where GapMind matches experiment) and discordant samples (where GapMind contradicts experiment).
(B) Stacked bar plots showing per-phenotype (top) and per-dataset (bottom) misclassification patterns.
Each bar displays proportions of true positives, true negatives, false positives (GapMind predicts complete pathway but no growth observed), and false negatives (GapMind predicts incomplete pathway but growth observed).
(C) Feature importance stability analysis using SHAP.
Top panel: number of stable features appearing in $\geq$70\% of model runs across random splits with 20 different random seeds.
Bottom panel: cross-dataset stability comparing individual dataset features to aggregated dataset (combination of the three other datasets) features.
Solid bars represent features common with the aggregated dataset; patterned bars represent dataset-unique features.
}\label{fig:misclassification_diagnosis}
\end{figure}

\begin{figure}[h]
\centering
\includegraphics[width=0.85\textwidth]{figure5.pdf}
\caption{
\textbf{Models learn mechanistic features when trained on concordant data and are able to predict some discordant samples.} All models use the same architecture and feature representation as in Figure 3; only the training set is restricted to concordant samples.
(A) Balanced accuracy of models trained on GapMind-concordant samples (where GapMind predictions match experimental outcomes) and tested on held-out concordant samples.
The plot compares random split (green line) and cross-dataset split (blue boxes) evaluation scenarios across 15 phenotypes.
(B) Cross-dataset feature stability analysis (similar to Figure 4C) for concordant-trained models using SHAP.
Stable features are defined as those appearing in $\geq$70\% of runs across random seeds (see Methods). The consistent recovery of canonical histidine catabolism genes (hutH, hutI, hutU) across datasets indicates that concordant training enables learning of transferable mechanistic features.
Solid bars: features common with aggregated dataset (combination of the three other datasets); patterned bars: dataset-unique features.
(C) Box plot showing balanced accuracy of concordant-trained models when applied to discordant samples across phenotypes. Performance on discordant samples varies substantially across phenotypes, consistent with heterogeneous causes of discordance; values near random indicate cases where genome-derived features are insufficient to resolve the phenotype.
Test performance is evaluated using Random (green) and Cross-dataset (blue) splits.
}\label{fig:concordant_analysis}
\end{figure}
