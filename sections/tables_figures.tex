\textbf{Diagnosing GapMind misclassifications and ML generalisation failures.}
(A) Conceptual framework outlining causes of concordant samples (where GapMind matches experiment) and discordant samples (where GapMind contradicts experiment).
(B) Stacked bar plots showing per-phenotype (top) and per-dataset (bottom) misclassification patterns.
Each bar displays the proportions of true positives, true negatives, false positives (GapMind predicts complete pathway but no growth is observed), and false negatives (GapMind predicts incomplete pathway but growth is observed).
(C) Feature importance stability analysis using SHAP.
Top panel: number of stable features appearing in $\geq$70\% of model runs across random splits with 20 different random seeds.
Bottom panel: cross-dataset stability comparing individual dataset features to aggregated dataset (combination of the three other datasets) features.
Solid bars represent features common to the aggregated dataset, and patterned bars represent dataset-unique features.
}\label{fig:misclassification_diagnosis}

\caption{
\textbf{Concordant-trained models learn mechanistic features and partially predict discordant samples.}
All models used the same architecture and feature representation as in Figure~3; only the training set was restricted to concordant samples.
(A) Balanced accuracy on held-out GapMind-concordant samples under random split (green line) and cross-dataset split (blue boxes) across 15 phenotypes.
(B) Cross-dataset feature stability analysis for concordant-trained models using SHAP (stable features are those that appear in $\geq$70\% of runs; see Methods).
Solid bars: features common to the aggregated dataset; patterned bars: dataset-unique features.
(C) Balanced accuracy of concordant-trained models applied to discordant samples.
Performance varied substantially across phenotypes; values near random indicate cases in which genome-derived features were insufficient to resolve the phenotype.
(D) Per-phenotype balanced accuracy on the full held-out cross-dataset test set (concordant + discordant pooled), with a stacked subpanel showing the proportion of each held-out test set in the concordant, false-positive-discordant, and false-negative-discordant categories.
The full-test balanced accuracy (median 0.67) falls between the concordant-only (panel A, median 0.89) and discordant-only (panel C) values, with the gap predominantly driven by false-positive-discordant samples for most phenotypes.
}\label{fig:concordant_analysis}
\end{figure}

\textbf{Effects of data filtering and feature selection on model performance.}
(A) Left: condensed summary of problematic genomes across datasets, showing the number of genomes in two discordant categories (no observed growth despite at least one GapMind growth prediction; universal observed growth despite incomplete GapMind pathways).
Right: top-20 most frequently misclassified microbes, ranked by number of phenotypes for which GapMind disagrees with the experimental label and coloured by membership in those discordant categories or neither category.
(B) Per-phenotype balanced accuracy on the cross-dataset split for three filtering strategies (concordant samples in blue; $Y_{\mathrm{soft}}$ confidence-filtered samples in green; problematic samples removed in red).
Numbers above each bar indicate the number of training samples removed by that filter relative to the full dataset; error bars show the standard deviation across replicate runs.
(C) Precision-recall scatter for the three filtering strategies and the GapMind baseline across phenotypes, with the dashed line indicating equal precision and recall.
(D) Combined-features (GapMind + KOFAM + RAST) versus phenotype-filtered (GapMind-only) balanced-accuracy scatter under random and cross-dataset splits; the dashed line marks equal performance, and points above the diagonal indicate that the phenotype-filtered feature set outperforms the combined set.
The inset shows the corresponding precision-recall distribution for combined features (blue) and phenotype-filtered features (red) using the same split-type marker shapes; the annotation gives paired Wilcoxon p-values across phenotype means.
}\label{fig:improvement_strategies}

\textbf{Sample size requirements for training generalisable models.}
Learning curves showing balanced accuracy as a function of training sample size for the histidine phenotype using GapMind-concordant data.
