\begin{figure}[ht]

\caption{
\textbf{Diagnosing GapMind misclassifications and ML generalisation failures.}
(A) Conceptual framework outlining causes of concordant samples (where GapMind matches experiment) and discordant samples (where GapMind contradicts experiment).
(B) Stacked bar plots showing per-phenotype (top) and per-dataset (bottom) misclassification patterns.
Each bar displays the proportions of true positives, true negatives, false positives (GapMind predicts complete pathway but no growth is observed), and false negatives (GapMind predicts incomplete pathway but growth is observed).
(C) Feature importance stability analysis using SHAP.
Stable KOs are those appearing in $\geq$70\% of model runs across 20 random seeds; KOs are then grouped into redundancy clusters using \texttt{shap.utils.hclust} so that paralogs and pathway-mates representing the same biological signal are counted as one entity (Methods).
Top panel: number of stable feature clusters when the model is trained on all four datasets combined.
Bottom panel: cross-dataset cluster stability comparing the stable feature clusters from the model trained on the held-out dataset alone to those from the model trained on the three other datasets combined.
Solid bars represent clusters shared between the held-out-alone and combined-of-three models; patterned bars represent clusters present only in the held-out-alone model.
}\label{fig:misclassification_diagnosis}
\end{figure}

\caption{
\textbf{Sample size requirements for training bounded specialist models.}
Learning curves showing balanced accuracy as a function of training sample size for the histidine phenotype using GapMind-concordant data.
Columns represent evaluation scenarios: (left) random holdout, (middle) cross-dataset, and (right) out-of-clade evaluations.
Rows represent test sample types: full (top), concordant (middle), and discordant (bottom).
Each point indicates performance at training sizes of 50, 100, 200, 500, or the full dataset. Performance on discordant test samples reflects the bounded value of concordant-trained models: some discordant cases retain genome-encoded signal beyond GapMind, whereas lack of saturation with additional training data indicates representational, not statistical, limits.
}\label{fig:model_sample_size_requirements}
\end{figure}
